SPIRITUAL AND MEDITATION SITE
==============================

Files:
- index.html: Complete website (HTML, CSS, jQuery, and JavaScript in one file)

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or another browser.
3. Enter your name, choose a meditation type, duration, and experience level.
4. Click "Begin Meditation" to see the session plan and countdown timer.

Note:
The page loads jQuery from its official CDN, so an internet connection is needed for the jQuery library.
The 1-minute option is provided for quick demonstration; 5, 10, and 15-minute options are also available.
